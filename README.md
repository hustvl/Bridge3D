Bridge3D equips pretrained 2D Vision–Language–Action models with 3D geometry guidance for precise robotic manipulation. **Implicit Fusion** augments image features with geometric priors from a 3D foundation model, while **Explicit Conditioning** grounds action denoising in an explicit 3D semantic field. Layer-wise linear probing identifies where geometric conditioning is most useful, improving learning efficiency. Experiments on RoboTwin 2.0 and six real-world tasks demonstrate improved spatial precision and data efficiency.
